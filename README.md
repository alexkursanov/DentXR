# DentXR — оценка убыли кости по прицельным снимкам

Учебный проект: модели YOLO26 находят зубы, эмалево-цементную границу (CEJ),
верхушки корней и гребень кости на прицельных снимках и считают
радиографическую убыль кости (%) для каждого зуба.

Данные: DenPAR — 1000 прицельных снимков, лицензия CC BY 4.0
(Rasnayaka et al., Scientific Data, 2025; <https://zenodo.org/records/16645076>).
